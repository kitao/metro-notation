## 転記規則

- `手順` 欄が回転記号の転記です。プライムの字形のみASCIIの `'` に統一します。
- 大文字・小文字を維持します。`r` と `R`、`l` と `L` を区別します。小文字の `l` は数字の `1` ではありません。
- `U2'` を `U2` に変えません。盤面の結果が同じでも、指で回す方向の情報が異なります。
- `R3` もそのまま保存します。`R'` に簡約しません。
- 手順内の空白は各回転の区切りです。原紙の改行や空白からトリガーの境界は決めません。
- `<br>` は紙面上の改行です。トリガーの境界、リグリップ、時間的な間を意味しません。
- 写真には回転記号の色、指の図、REGRIP、若葉マークがあります。回転列とは別の列に記録します。
- `転記済` は回転記号の全文を写真から読めたことを意味します。キューブを実際に回した検証や、色・図の完全なデータ化まで完了した意味ではありません。
- `要確認` の行には読めた範囲だけを残します。`…` は判読不能または写真外の部分で、回転記号ではありません。採用時にはエラーとして扱い、黙って省略してはいけません。
- 他の一般的な手順、手順の数学的な同値性を使って、読めなかった文字を補いません。

## 色・指づかい・持ちなおし

紙面上部の凡例を、次の意味として保存します。

| 表示 | 紙面の意味 | データ化時の扱い |
| --- | --- | --- |
| 青 | トリガー | 対象の回転に付随する属性 |
| オレンジ | プッシュ | 対象の回転に付随する属性 |
| 灰 | 図の指でまわす | 手の図との対応も必要 |
| REGRIP | 持ちなおし | 回転の間に入る操作。`x/y/z` とは区別 |
| 若葉 | 若葉マーク | マークの有無を保存。独自の難易度に読み替えない |
| チェック欄 | 学習状況の記入欄 | 写真のチェック状態を手順の属性にしない |

各手順の「色」欄は `P3:U` のように記録します。`P` はオレンジ（プッシュ）、`T` は青（トリガー）、数字は**手順先頭からの1始まりの回転番号**、コロンの後は該当する回転です。改行やREGRIPを番号に数えません。`未照合` は色の有無をまだ確定していない意味です。

「注記」の `REGRIP→n` はn番目の回転の直前です。`左手REGRIP` と読めたものは区別します。右手のREGRIPの向き（R方向/R'方向）や指の図の細部が判別できない場合、勝手に具体化しません。

色の転記は初回の目視記録です。影・反射・印刷のにじみがあるため、**回転列とは別に再照合が必要**です。黒と灰の完全な区別、指の種類、REGRIPの向きは未確定です。`—` はこの段階で転記した色・注記がないことを意味し、原紙に絶対に存在しないことの保証ではありません。

## キューブ図とレイアウト

回転列と文字注記に加え、OLL上面3×3と[F2L識別図41件](f2l-diagrams.md)を構造化しています。F2LはP5/P6との目視照合後、表示方向・省略色・隠れた側面の色を固定データにしました。**OLLの全側面とPLLの矢印などは未構造化です。** 原写真に保持しています。

今後の図のデータ化では、以下を別々に扱います。

1. ケースの識別用のキューブ状態と表示方向。
2. 実際に回す手順の開始時の向きと、冒頭のU/U'などの調整。
3. 図中の強調色、省略色、矢印。
4. メトロ記法用の区切り。原紙の空白や改行から自動的に決めない。

手順を逆再生して作った図は「写真の図の転記」とは別物です。独立した根拠なしに置き換えません。

## 検証

2026-09-20時点で、F2L 41件・OLL 57件・PLL 21件、計119件の回転列を全文転記し、下記の検査を通過しています。指づかいの詳細、完全なキューブ図の照合は未完了です。

```sh
python3 scripts/check_reference.py
# 未確定の回転列があれば終了コード1になる採用前チェック:
python3 scripts/check_reference.py --require-complete
```

検査内容:

- 番号・件数・重複・回転記号の構文。
- 色の注記が指す回転番号と、その回転の文字の一致。
- 54ステッカーの回転モデルによる逆再生。F2Lはクロスと他の3スロットを維持すること、OLLは下2層が揃っていること、PLLは下2層と上面の向きが揃っていること。
- 全57件のOLLについて、逆再生した上面3×3と、写真から独立して目視転記した上面の一致。

この検査は「逆再生してから順再生すれば戻る」という恒等性だけを見るものではありません。開始状態が各段階の条件に合うか、OLL上面が写真に一致するかを確認します。ただし、異なるケースや指づかいでも同じ検査を通る可能性は残ります。**検査通過を写真との完全一致の証明にしません。**

照合中に見つかった事項:

- F2L 26: 初回に3手目を `R'` と誤読。構造検査で検出し、P2を拡大して `r'` と確認・修正。
- OLL 35: P1で切れていた2行目をP3で確認。
- PLL T・Y: 下端に接していた2行目をP2の拡大表示で照合。
- PLL Gc・Nb・Rb: P2の反射・写真外の部分を推測せず保留し、追加のP4で全文を確認。RbはP2では見えていなかった1行目末尾の `D R` を補完。
