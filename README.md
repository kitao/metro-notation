# Metro Notation

**Metro Notation** turns Rubik's Cube algorithms into metro-style diagrams, making move sequences easier to remember as shapes.

**Metro Notation**は、ルービックキューブの手順を路線図のような図形で表す記法です。一連の動きを形で覚えられます。
